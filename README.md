# RoadVision AI

Intelligent Road Damage Detection and Maintenance Prioritization System using Computer Vision.

## Objective
Automatically detect road damages (potholes, cracks) from images/videos and prioritize maintenance.

## Tech Stack
- Python 3.11
- YOLOv8 (Ultralytics)
- PyTorch
- OpenCV
- Streamlit

## Project Structure
```
RoadVision-AI/
├── data/ # Dataset
├── notebooks/ # Jupyter notebooks
├── src/ # Source code
│ ├── config.py
│ └── data_loader.py
├── app/ # Streamlit app
├── models/ # Trained models
├── utils/ # Helper functions
└── requirements.txt
```
